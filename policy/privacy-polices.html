Privacy Policy / 隐私政策

Last Updated: 2026-04-16

This Privacy Policy applies to the browser extension TMC Wiki File Sync ("the Extension").

本隐私政策适用于浏览器扩展 TMC Wiki File Sync（以下简称“本扩展”）。

1. Single Purpose / 单一用途

The Extension has a single purpose: helping users export documents from toca.17u.cn / wiki.17u.cn and import them into a user-configured Wiki knowledge base in one click.

本扩展仅用于一个目的：帮助用户将 toca.17u.cn / wiki.17u.cn 的文档一键导出并导入到用户自行配置的 Wiki 知识库中。

2. Data We Access / 我们访问的数据

  • Document metadata such as file id (fid) and filename, required for export/import workflow.
  • Authentication cookies on source pages (for example token, userId, spaceId, deviceId) only to call source export APIs on behalf of the signed-in user.
  • User configuration stored locally: Wiki base URL, token, username, selected knowledge base id, and KB list.
  • 文档元数据（如 fid、文件名），用于导出与导入流程。
  • 源页面认证 Cookie（如 token、userId、spaceId、deviceId），仅用于代表用户调用导出接口。
  • 本地配置数据：Wiki 地址、Token、用户名、已选知识库 ID、知识库列表。

3. How Data Is Used / 数据用途

Data is used only to complete the user-initiated sync flow:

  • Create export task on source platform
  • Download exported file
  • Upload file to user-configured Wiki backend
  • Poll import task status and show progress in the page UI

数据仅用于完成用户主动触发的同步流程：

  • 创建导出任务
  • 下载导出文件
  • 上传文件到用户配置的 Wiki 后端
  • 轮询导入状态并在页面显示进度

4. Permissions Usage / 权限用途

  • host permissions: access source and target domains and user-configured Wiki endpoint for file sync.
  • storage: store local configuration and login state.
  • activeTab: bind sync status updates to the current tab.
  • background: run long-lived export/import workflow reliably.
  • downloads: observe download lifecycle for sync diagnostics.
  • scripting: read required cookies from source page context.
  • tabs: open setup page and send status updates to tab.
  • webRequest: observe export download request metadata in a narrow URL scope.

5. Data Sharing and Selling / 数据共享与出售

We do not sell personal data. We do not share data with third-party advertisers or data brokers. Data is transmitted only to the source system and the Wiki backend explicitly configured and used by the user.

我们不会出售个人数据，也不会向广告平台或数据经纪商共享数据。数据仅在用户操作下传输给源系统以及用户自行配置的 Wiki 后端。

6. Remote Code / 远程代码

The Extension does not download and execute remote code. All executable code is packaged with the extension at build/publish time.

本扩展不下载并执行远程代码。所有可执行代码均在发布时打包在扩展内。

7. Data Retention and Security / 数据保留与安全

Local configuration remains in browser local extension storage until the user logs out, clears extension data, or uninstalls the extension.

本地配置数据存储于浏览器扩展本地存储中，直至用户退出登录、清理扩展数据或卸载扩展。

8. User Control / 用户控制

  • Users can log out in extension settings to clear authentication state.
  • Users can remove the extension at any time to stop all data processing.
  • Users can update or clear locally stored settings in the extension UI.
  • 用户可在设置中退出登录，清除认证状态。
  • 用户可随时卸载扩展，停止所有数据处理。
  • 用户可在扩展界面修改或清空本地配置。

9. Contact / 联系方式

If you have questions about this Privacy Policy, please contact the developer through the extension support channel or project repository: https://github.com/tmc/tmc-wiki-chrome-ext.

如对本隐私政策有疑问，请通过扩展支持渠道或项目仓库联系开发者： https://github.com/tmc/tmc-wiki-chrome-ext。
